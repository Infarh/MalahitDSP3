# Malahit DSP3 — управление и захват сырого I/Q

Python-инструментарий для SDR-приёмника Malahit DSP3, подключённого по USB.
Устройство предоставляет три аудио-эндпоинта и последовательный порт;
вендорского SDK нет, для обычной работы драйвер libusb не требуется.

## Как устройство видится в Windows

Композитное USB-устройство `VID_FFFF&PID_0737` (Bus reported description:
`Malahit reciever`).

| Интерфейс | Эндпоинт | Назначение |
|---|---|---|
| `MI_00` | COM-порт (usbser) | управление по CAT, 115200 8N1 |
| `MI_02` | `Malahit RX` | демодулированный звук, 48 кГц моно |
| `MI_04` | `Malahit IQ` | сырая панорама I/Q, 192 кГц стерео (L=I, R=Q) |
| `MI_06` | `Malahit Headphone` | выход на наушники, 48 кГц |

Аудио-эндпоинты открываются через **WDM-KS**, который не поддерживает
блокирующий API PortAudio. Захват всегда идёт через callback-поток
(`IqStream` в [malahit.py](./malahit.py) это делает).

## Установка

```powershell
python -m pip install -r requirements.txt
```

## Использование

```powershell
python malahit.py info                    # порты, идентификация CAT, аудиоустройства
python malahit.py get                     # частота, модуляция, S-метр
python malahit.py tune 100.5M             # настройка (100.5M / 7100k / 145500000)
python malahit.py tune 7.1M --mode 2      # 2 = USB
python malahit.py scan 87.5M 108M --step 100k
python malahit.py record fm.wav 100.5M --seconds 10
python malahit.py demod fm.wav audio.wav
```

`record` пишет стерео WAV 16 бит / 192 кГц — этот формат HDSDR, SDR# и SDR++
открывают напрямую как файл I/Q.

## Набор CAT-команд (прошивка 2.62)

Приёмник реализует подмножество Kenwood TS-480. На `ID;` отвечает `ID021;`.
Перебором всех 676 двухбуквенных команд проверено, что отвечают только эти 22:

`AG AI AN DA FA FB FR FT FV FW GC ID IF KS KY MD PA PS PT RA SH SL SM`

Замечания и подводные камни:

- `SM` в версии 2.62 требует параметр — работает `SM0;`, а голый `SM;`
  возвращает `?;` (в 2.20C работал и без параметра).
- `FV;` на любой прошивке возвращает `FV1.00;` — это жёстко прописанный
  литерал в таблице ответов, а **не** версия прошивки.
- Команды, сообщающей версию прошивки, в CAT нет. Смотреть в меню RADIO
  на самом приёмнике.
- Частота — всегда 11 цифр в герцах с ведущими нулями:
  `FA00010050000;` = 100.5 МГц.
- На неподдерживаемые команды устройство отвечает `?;`.
